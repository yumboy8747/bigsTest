# 빅스홀딩스 프론트 테스트 😊

### 실행 가이드
1. 프로젝트 클론

   `git clone https://github.com/yumboy8747/bigsTest.git `
   - 프로젝트를 로컬 환경에 가져옵니다.


2. 프로젝트 디렉토리로 이동
      
   `cd bigsTest`
    - 클론한 프로젝트 디렉토리로 이동합니다.


3. 패키지 설치
   
   `yarn install`
    - 프로젝트에서 사용하는 의존성을 설치합니다.


4. 프로젝트 실행

   `yarn start`
    - 개발 서버를 실행하여 프로젝트를 로컬에서 확인할 수 있습니다.


---

### 버전 관리
- React : 18.3.0
- TypeScript : 4.9.5
- Node.js : v22.9.0 (LTS)
- Yarn: v1.x 이상
